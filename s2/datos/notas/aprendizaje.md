# Plan de aprendizaje ficticio

Objetivo de Alex: aprender a construir agentes de IA con Python durante seis semanas. Puede estudiar cuatro horas por semana. Semana 1: Python asíncrono y tipos. Semana 2: herramientas y APIs. Semana 3: RAG y memoria. Semana 4: MCP. Semana 5: orquestación. Semana 6: evaluación y despliegue.

## Recursos

Consultar el repositorio público pydantic/pydantic-ai para encontrar ejemplos. El número de estrellas debe obtenerse de la API cuando se solicite un dato actual. No inventar métricas. Distinguir documentación oficial de opiniones de terceros.
