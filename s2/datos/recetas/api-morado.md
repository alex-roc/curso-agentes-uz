# Api morado con pastel (receta ficticia)

Bebida caliente de maíz morado, típica del desayuno en Cochabamba. Para cuatro tazas: 250 gramos de harina de maíz morado, un litro y medio de agua, dos ramas de canela, cuatro clavos de olor, la cáscara de una naranja y azúcar al gusto.

## Preparación

Disolver la harina en medio litro de agua fría. Hervir el resto del agua con la canela, el clavo y la cáscara de naranja. Añadir la harina disuelta y remover sin parar durante quince minutos, hasta que espese. Servir muy caliente, con un pastel de queso frito.
